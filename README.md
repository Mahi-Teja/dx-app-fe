# Dx Tracker Frontend

### Daily Expense Tracker.

A modern, responsive financial tracking interface built to provide real-time insights into your **Balance**, **Income**, and **Expenses**.

## 🚀 Features

- **Financial Summary Cards:** Real-time calculation of Total Balance, Income, and Expenses.
- **Responsive UI:** Fully optimized for Mobile, Tablet, and Desktop views.
- **Transaction Tracking:** Dynamic list showing recent financial activities.

## 🛠️ Tech Stack

- **Framework:** [React.js](https://reactjs.org/) (or Next.js)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Data Fetching:** [Axios](https://axios-http.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
